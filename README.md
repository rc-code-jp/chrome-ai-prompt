# Prompt Spark

入力欄で `$$` と打つと、保存しておいたプロンプトを確認モーダルから呼び出して挿入する Chrome 拡張機能です。
Claude / Gemini（Gmail 内の Gemini 欄を含む）など、どのサイトの入力欄でも使えます。

## インストール（開発版）

1. `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選ぶ
3. 初回インストール時にサンプルのプロンプトが 3 件登録される

コードを変更したら拡張機能カードの再読み込みボタンを押し、対象ページもリロードしてください。

## 使い方

| 操作 | 動作 |
| --- | --- |
| `$$`（全角 `＄＄` も可）を入力 | 確認モーダルを開く |
| `↑` `↓` / `Tab`、クリック | プロンプトを選ぶ |
| `Enter`、「挿入する」、ダブルクリック | `$$` を選んだプロンプトに置き換える |
| `Esc`、「キャンセル」、モーダルの外をクリック | 閉じて `$$` を削除する |

- プロンプトの登録・編集・削除は、ツールバーのアイコンから開くポップアップで行います。
- 文字として `$$` を入力したいときは貼り付けてください（貼り付けではモーダルは開きません）。
- 挿入はエディタの undo 履歴に残るので、`⌘Z` / `Ctrl+Z` で戻せます。

## 入力イベントの扱い

- 入力欄ごとにリスナーを付けず、`window` の capture フェーズで `input` / `compositionend` を 1 か所で受け取ります。
  React などが描画し直して要素が入れ替わっても検出できます。
- 日本語入力の変換中は反応せず、確定（`compositionend`）した時点で判定します。
- モーダル表示中もフォーカスは元の入力欄に残し、キー入力は拡張機能側で受け取ってページには渡しません。
  そのため、Enter で送信されるサイトでも誤送信は起きません。
- 挿入は `document.execCommand('insertText')` で行います。ブラウザ本来の編集として扱われるため、
  React の制御コンポーネント、ProseMirror（Claude）、Quill 系エディタ（Gemini）の内部状態にも正しく反映されます。
- 対象: `textarea`、`input`（type が text / search / url / tel）、`contenteditable`。パスワード欄などは対象外です。

## 構成

```
manifest.json          Manifest V3（全サイト・全フレームに content script を注入）
src/content.js         $$ の検出、確認モーダル（Shadow DOM）、置き換え
src/manager.html/css/js  ポップアップ兼オプションページ（プロンプト管理）
src/background.js      初回サンプル登録、モーダルから管理画面を開く中継
icons/                 scripts/generate-icons.py で生成
```

プロンプトは `chrome.storage.local` に保存され、外部には送信されません。
